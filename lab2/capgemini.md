The **Orange + Capgemini → Bleu** case is a good example because they actually created a **new company together** to solve a specific problem.

### What is Bleu?

[Orange](https://www.orange.com?utm_source=chatgpt.com) and [Capgemini](https://www.capgemini.com?utm_source=chatgpt.com) created a **50/50 joint venture called Bleu**. Bleu is a French cloud company designed mainly for organizations that handle highly sensitive information, such as the **French government, hospitals, financial institutions, utilities, and other critical infrastructure organizations**. ([Capgemini][1])

The basic structure is:

**Orange + Capgemini → create Bleu → Bleu provides a secure French cloud**

But there's also a third important company involved: [Microsoft](https://www.microsoft.com?utm_source=chatgpt.com).

Microsoft provides the underlying technologies, particularly **Microsoft Azure and Microsoft 365**. Bleu makes those technologies available through a separate cloud environment operated in France. ([Microsoft][2])

### Why did they create it?

Imagine a French hospital wants to use Azure to store and process sensitive patient information.

Using ordinary global cloud infrastructure can raise questions about **where the data is stored, who operates the infrastructure, which country's laws apply, and whether the service meets French cybersecurity requirements**.

Bleu's model is designed to address those concerns. Its data centers and operational centers are in France, the services are operated by Bleu personnel, and the environment is separate from Microsoft's global public-cloud infrastructure. Bleu is also pursuing France's **SecNumCloud 3.2** qualification, the cybersecurity framework administered by ANSSI. ([Bleu][3])

So conceptually:

> **Microsoft provides the cloud technology → Orange and Capgemini created and own Bleu → Bleu operates that technology within a French-controlled environment → sensitive French organizations can use Azure/Microsoft 365 under that model.**

### What does each company contribute?

**Orange** brings experience with telecommunications, networks, infrastructure, cybersecurity and operating large-scale digital services.

**Capgemini** brings IT consulting, systems integration, cloud transformation and experience helping large organizations migrate and operate their technology.

**Microsoft** supplies the underlying Azure and Microsoft 365 technologies. Microsoft describes Bleu as a separate instance of its cloud services operated by independent local partners rather than Microsoft's normal public cloud. ([Microsoft][2])

That's why it is an interesting **alliance**: instead of each company trying to build everything independently, they combine complementary capabilities.
